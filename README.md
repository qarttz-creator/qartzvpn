# Qarttz VPN — простой клиент (одна кнопка)

Настоящий VPN: весь трафик компьютера идёт в туннель (режим TUN), а не только то,
что умеет ходить через системный прокси. Для пользователя — одно окно, выбор сервера
и кнопка «Подключить». Остальное зашито внутрь.

## Установка (для пользователя)

Скачать `QarttzVPN-Setup.exe` из [релизов](../../releases), запустить, пройти установку.
Ядра `xray` и `sing-box` уже внутри установщика — ничего докачивать и копировать не нужно,
.NET ставить тоже не нужно. После установки — ярлык «Qarttz VPN», выбрать сервер,
нажать «Подключить». Windows попросит права администратора — это обязательно для TUN.

## Как устроено (гибрид из двух движков)

- **xray.exe** держит reality-туннель к серверу (VLESS+Reality — то же ядро, что в
  v2rayTun, полная совместимость) и отдаёт локальный SOCKS на `127.0.0.1:24808`.
- **sing-box.exe** создаёт TUN-адаптер и заворачивает весь трафик ОС в этот SOCKS,
  плюс маршруты, DNS и kill-switch.

Почему так: sing-box сам по себе не согласует постквантовый reality этого
xray-сервера, а xray — согласует. Поэтому reality за xray, а TUN за sing-box.
Клиент (`QarttzVPN.exe`) запускает оба процесса и гасит их по «Отключить».

## Профили серверов

Добавить сервер — кнопка **«Профили…»** в окне клиента: вставить `vless://` ссылку
(из 3x-ui, вкладка «Ссылки»), сохранить — список сразу обновится. Имя в выпадающем
списке берётся из части после `#` в конце ссылки, строки с `#` в начале — комментарии.
Под капотом это файл `profiles.txt` (по ссылке на строку). При подключении из выбранного
профиля на лету генерируется конфиг xray, а IP самого сервера автоматически исключается
из туннеля (иначе петля). При обновлении клиента список серверов не затирается.

## Исключения (кнопка «Исключения…» или `exclude.txt`)

Адреса/подсети, которые должны идти МИМО туннеля напрямую. По умолчанию пусто — всё
в туннель. Кто понимает — вписывает локальные/корпоративные сети, чтобы не терять к ним
доступ:
```
192.168.0.0/16
10.0.0.0/8
```
Правится прямо из окна клиента (кнопка «Исключения…») или в файле `exclude.txt`.
Изменения применяются при следующем «Подключить». При обновлении клиента этот файл
не затирается.

## Файлы

| Файл | Назначение |
|---|---|
| `Program.cs`, `MainForm.cs` | оболочка: окно, список серверов, кнопка, трей (C#, WinForms) |
| `VlessProfile.cs` | разбор `vless://` ссылки и генерация xray-outbound |
| `SingBoxManager.cs` | запуск/остановка xray+sing-box, генерация конфигов |
| `config.template.json` | шаблон конфига sing-box (TUN, маршруты, socks→xray) |
| `profiles.txt` | список серверов (vless-ссылки) |
| `exclude.txt` | адреса мимо туннеля (правки пользователя) |
| `app.manifest` | запуск от администратора (нужно для TUN) |
| `installer/QarttzVPN.iss` | скрипт установщика Inno Setup |
| `.github/workflows/build.yml` | автосборка: app + ядра + установщик |
| `core/` | сюда ядра кладёт CI (локально — вручную, см. ниже) |

## Релиз (автосборка на GitHub)

Сборка идёт на Windows-раннере GitHub Actions: публикует приложение, скачивает
последние стабильные `xray` и `sing-box`, кладёт их внутрь и компилирует
`QarttzVPN-Setup.exe`.

- **Выпустить версию:** создать и запушить тег `vX.Y.Z` —
  ```
  git tag v1.0.0
  git push origin v1.0.0
  ```
  Через несколько минут установщик появится в разделе Releases.
- **Пробная сборка без релиза:** вкладка **Actions → build → Run workflow**
  (установщик будет в артефактах прогона).

## Локальная сборка (для разработки)

1. .NET SDK 8: https://dotnet.microsoft.com/download/dotnet/8.0
2. Положить в `core\` два файла (в репозиторий они не коммитятся):
   - `xray.exe` — https://github.com/XTLS/Xray-core/releases (Xray-windows-64.zip)
   - `sing-box.exe` — https://github.com/SagerNet/sing-box/releases, стабильная версия
3. Собрать:
   ```
   dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true
   ```
   Результат — в `bin\Release\net8.0-windows\win-x64\publish\`.

## Если не подключается

- **«Не найден core\xray.exe / sing-box.exe»** — ядра не доехали; переустановите из
  свежего `QarttzVPN-Setup.exe` (при локальной сборке положите их в `core\`).
- **TUN не поднимается («configure tun interface: cannot find the file»)** —
  перезагрузите Windows (драйвер wintun залипает после неудачных попыток).
  Отдельной dll wintun не нужно — он внутри sing-box.exe.
- **«порт занят / Only one usage of each socket address»** — висит старый процесс:
  `Get-Process xray,sing-box -EA SilentlyContinue | Stop-Process -Force`
- **Лог** клиента — `qvpn.log` рядом с `QarttzVPN.exe`.

## Ключи

UUID и публичный ключ reality — клиентские данные (их и так раздают в ссылках), держать
в раздаваемом установщике нормально. Приватных ключей сервера здесь нет.
