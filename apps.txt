# Приложения, чей трафик идёт НАПРЯМУЮ, мимо туннеля (сплит-туннель по процессу).
# Нужно для программ с «плавающими» и неизвестными адресами — онлайн-игры и т.п.,
# где фильтр по IP не поможет.
#
# По одному имени исполняемого файла на строку. Путь не нужен — только имя exe.
# Строки, начинающиеся с #, игнорируются (комментарии).
# Удобнее редактировать из клиента: кнопка «Приложения мимо туннеля…».
#
# Примеры (без решётки в начале):
# Discord.exe
# LeagueOfLegends.exe
# cs2.exe
