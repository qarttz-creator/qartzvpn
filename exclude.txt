# Адреса и подсети, которые идут МИМО туннеля (напрямую).
# По одной записи на строку. Можно IP или CIDR. Строки с # игнорируются.
# По умолчанию список пуст — весь трафик идёт в туннель (кроме самого VPN-сервера,
# его sing-box обходит автоматически).
#
# Примеры (раскомментируйте при необходимости):
# 192.168.0.0/16      # домашняя/корпоративная локальная сеть
# 10.0.0.0/8          # корпоративная сеть
# 172.16.0.0/12       # корпоративная сеть
# 203.0.113.10        # конкретный сервис, которому нужен ваш реальный IP
